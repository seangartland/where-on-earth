**Verdict: fix the page design, narrowly and conditionally. Keep persistent geographic pages; replace oversized context allocation before adding a second renderer path. Do not start the renderer pilot yet.** The revision fits 38/41 reference windows. Each remaining window exceeds residency by 5,122,200 bytes; Madrid natural also exceeds transfer by 9,687 bytes. Two full-resolution context half-pages would save 5,613,904 resident bytes, enough to close that specific memory deficit without changing z9 detail, mip policy, gutters or the 40-texture cap. Their encoded transfer is not measured. This is a bounded context correction recommendation, not a declaration that Stage 2 passes.

There is a larger qualification in the evidence: the additional phone landscape table fails Congo, Great Lakes and ocean too. A correction of the three headline reference failures alone cannot authorize renderer entry. I am explicitly revising the previous review's stop-after-one-recut recommendation because the remaining reference deficit has an identifiable context-only remedy. Permit one context feasibility check covering both tables, then stop geometry iteration if it cannot close them. No world build follows from this memo.

**The specific 7x10 remedy is fixed geographic 4x2 z5 strips at original resolution.** Keep 2x2 z9 and existing z7 pages. For the three failing reference windows, replace each of their two 4x4 z5 pages with the adjoining half facing the shared boundary. Generate strips from the resolved original mosaic, with fresh two-pixel neighbor gutters and provenance, not by recompressing page JPEGs. Give each strip an immutable geographic key and content version. Retain the existing plans for the other 38 reference windows in this bounded comparison.

The geometry can be checked directly from the reported keys. Madrid natural's z9 pages span y=93..99, covering source z9 rows 186..199; Madrid shift spans 94..100, covering rows 188..201. Ordinary-land natural also spans 94..100. Dividing by 16 maps each envelope to z5 rows 11 and 12. This preserves the geographic extent used by the report. It does not prove that a wider early-zoom view or zoom reversal needs no additional context.

A 1028x516 strip has a full mip chain of 2,828,544 bytes: sum `4 * max(1, floor(1028/2^l)) * max(1, floor(516/2^l))` through 1x1. Two strips replace two 5,635,496-byte squares. The failing footprint becomes:

`35 * 1,419,688 + 2 * 5,635,496 + 2 * 2,828,544 = 66,617,160 bytes`, with 39 textures.

That leaves only 491,704 bytes under the resident cap. This is not room for an additional full page or simultaneous old/new replacement. Reserve the union of visible, pinned and incoming allocations; load the chosen representation directly. Never count an old square as freed while the GPU still owns it. Required wider context or allocation overhead can invalidate this estimate. Keeping full squares compressed while uploading strips would save residency but would leave Madrid natural's transfer failure, so the proposed transfer remedy requires separately encoded strip assets.

**The source seams gate final map acceptance for either renderer.** The report lists ten flagged page cases: five continuous, four suspect and one suspect without an assessable neighbor. These are not ten independent joins: the 5/1/2 south and 5/1/3 north measurements describe the same boundary. The worst reported edge, 5/3/2 south, has p99 219 against control values 47..110, with a reported visible discontinuity. Gutters and persistent storage cannot repair a discontinuity already inside the resolved source mosaic.

Trace each flagged edge to original source identities, masks, fallback choices, alignment and color processing. Resolve both sides consistently in geographic space; correct the offending source selection or processing before regenerating affected levels, strips, pages and gutters. Do not blur across the line merely to lower the statistic. Recheck against resolved originals at matched ground scale, including the missing-neighbor case once its intended source is known. Update hashes and versions for every affected derivative and rerun transfer sums. Statistical outliers alone do not identify the cause, especially at real coastlines. I did not independently inspect the crops in this review; the visible seam finding is attributed to the supplied evidence.
